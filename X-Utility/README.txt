X Utility 2.0.14
==============

Chrome/Edge용 Manifest V3 확장 프로그램입니다.
로그인된 X 웹 세션을 이용해 게시글·마음에 들어요 정리와 팔로워 기록·비교를 돕습니다.

기능
----
- 본인 게시글·답글 정리 및 고정 게시글 보존 선택
- 마음에 들어요 일괄 취소
- 전체 팔로워 목록을 날짜별로 기록하고 두 시점 비교
- 새 팔로워·사라진 팔로워·유지 중인 팔로워와 재팔로우 이력 확인
- 실행 전 확인, 실행 중 취소, 중복 실행 방지 및 요청 제한 안내

설치
----
1. ZIP을 고정된 위치의 폴더에 압축 해제합니다.
2. Chrome에서는 chrome://extensions, Edge에서는 edge://extensions를 엽니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 선택합니다.
4. manifest.json이 들어 있는 폴더를 선택합니다.
5. 로그인된 X 탭을 새로고침합니다.

업데이트 및 기존 기록 보존
-------------------------
기존 확장 프로그램을 제거하지 마세요. 현재 설치 폴더의 경로를 유지한 채
새 ZIP의 내용을 그 폴더에 덮어쓴 후 확장 프로그램 관리 화면에서 다시 로드하고,
X 탭과 팔로워 비교 화면을 새로고침하세요.

가능하면 업데이트 전에 기존 설치 폴더를 별도로 복사해 보관하세요.
다른 경로에 새로 설치하면 확장 프로그램 ID가 달라져 기존 기록에 접근하지
못할 수 있습니다. 기존 설치 폴더를 사용한 새로고침 방식으로 업데이트하세요.
2.0.9에서는 IndexedDB 이름, 버전 및 저장 구조를 변경하지 않습니다.

사용 방법
---------
게시글 정리:
본인 프로필의 게시글 또는 답글 페이지에서 팝업을 열고, 고정 게시글 보존 여부를
선택한 뒤 '게시글 청소하기'를 누릅니다. 삭제 안내를 확인한 후 실행하세요.

마음에 들어요 정리:
X의 마음에 들어요 목록을 선택한 상태에서 팝업의 '마음에 들어요 청소하기'를
누릅니다. 해당 페이지에서만 실행할 수 있습니다. 게시글 자체를 삭제하지 않고
마음에 들어요만 취소합니다. 완료 안내는 '완료'를 눌러야 닫힙니다.
X 요청 제한이 발생하면 최대 60초 동안 대기한 뒤 1회 자동 재시도합니다.
X가 60초보다 긴 대기를 요구하면 작업을 종료하고 안내합니다.
대기 중에도 취소할 수 있으며, 반복 제한 또는 긴 대기 시간은 종료 안내가 표시됩니다.
실패·취소 안내는 '닫기'를 눌러 닫을 수 있습니다.

팔로워 기록·비교:
1. 본인 프로필의 전체 팔로워 페이지에서 '현재 팔로워 기록'을 누릅니다.
   '인증된 팔로워' 페이지는 기록 대상이 아닙니다.
2. 수집 중에는 X 탭을 닫지 마세요. 실행 중 취소할 수 있습니다.
3. 나중에 다시 기록하고 팝업의 '변화 확인'을 누릅니다.
4. 같은 계정의 서로 다른 두 기록을 선택해 비교합니다.
5. 사용자 행을 선택하면 이력을 확인하고, 더블클릭하면 계정 프로필을 엽니다.

비교는 이름이나 @아이디 대신 X 계정 고유 ID를 기준으로 합니다.
팔로워 목록에서 사라졌다는 사실만으로 언팔로우·차단·계정 정지 등의 원인을
확정할 수는 없습니다. 기존 기록을 시작으로 이후 변화만 비교할 수 있습니다.
팔로워 수집이 실패한 경우에는 새 기록을 저장하지 않습니다.

데이터 보관
-----------
팔로워 기록은 이 확장 프로그램의 로컬 IndexedDB에 계정별로 저장됩니다.
확장 프로그램 전용 외부 서버로 기록을 업로드하지 않습니다.
X 조회·삭제·취소 요청은 X로 전송되며, 프로필 이미지를 표시할 때 이미지
주소에 대한 요청이 발생할 수 있습니다.

로그인 세션의 인증 헤더는 실행 중 메모리에서 사용하고, 쿠키는 필요할 때
X 탭에서 읽습니다. 인증값을 팔로워 기록이나 별도 영구 저장소에 저장하지 않습니다.

확장 프로그램 제거, 브라우저 프로필 삭제, 확장 프로그램 저장 데이터 삭제 시
팔로워 기록이 사라질 수 있습니다. 삭제된 로컬 기록을 자동 복구하는 기능은 없습니다.

사용 전 주의사항
----------------
요청 간격 조절과 서버 대기 시간 반영·최대 60초 자동 대기·1회 재시도를 적용해 과도한 요청을 줄이도록
설계했습니다. 다만 X의 비공식 자동화 방식을 사용하므로, 계정 이용 제한이나
일시·영구 정지 가능성이 있으며 이를 완전히 방지할 수는 없습니다.

이러한 위험을 충분히 이해한 뒤 사용해 주세요. 이용 제한이나 정지로 잃으면
곤란한 중요한 계정에는 사용을 권장하지 않습니다.

- 삭제된 게시글은 이 도구로 복구할 수 없습니다. 마음에 들어요 취소도 자동으로
  되돌리는 기능이 없습니다. 실행 전 대상 페이지와 확인 안내를 읽어 주세요.
- X의 내부 구조가 변경되면 기능이 동작하지 않을 수 있습니다.
- 요청 제한·로그인 오류가 나타나면 반복 실행하지 말고 상태를 확인하세요.
- 실제 계정 사용에는 위험이 있습니다. 소량 테스트로도 안전성이 보장되지 않습니다.

2.0.9 수정 내용
- 게시물 외 객체를 게시물로 수집하지 않도록 수정했습니다.
- 같은 목록이 새 커서로 3회 연속 반복되면 실패 안내 후 조회를 멈춥니다.
- Retry-After를 우선 반영하고, reset 시각은 서버 Date를 기준으로 계산합니다.
- 게시글 정리 화면의 진단 내용 복사로 상태 코드, 제한 헤더, 조회·삭제 건수를 확인할 수 있습니다. 인증 정보와 게시글 본문은 포함하지 않습니다.

2.0.10 수정 내용
- 직접 새 정리를 시작하면 이전 작업의 제한 기록만으로 중단하지 않고 현재 응답을 확인합니다.
- 진단에서 이전 제한 기록(previous-limit)과 새 서버 응답(response)을 구분합니다.
- 같은 작업 안에서의 제한 대기·1회 재시도 상한은 유지합니다.


2.0.11 수정 내용
- 고정 게시물 보존을 선택했을 때만, 같은 본인 고정 게시물만 반복되는 목록의 조회를 마치고 답글 목록으로 넘어갑니다.
- 보존을 해제하면 고정 게시물도 삭제 대상으로 처리하며 반복 고정글을 이유로 조회를 조기 종료하지 않습니다.
- 삭제 0.5초·조회 0.3초 간격과 기존 팔로워 기록 저장 구조를 유지합니다.


2.0.12 수정 내용
- 진단 내용 복사 버튼을 제거했습니다.
- 게시글·마음에 들어요 정리 화면의 중앙 정렬, 제목, 진행 건수, 안내, 버튼 양식을 통일했습니다.
- 삭제·조회 간격, 고정글 제외 처리 및 팔로워 기록 저장 구조는 유지합니다.


2.0.13 수정 내용
- 게시글·마음에 들어요 정리 버튼을 남색으로 통일했습니다.


2.0.14 수정 내용
- 양식은 통일하되 게시글 정리는 남색, 마음에 들어요 정리는 기존 빨강 계열 테마색으로 적용합니다.
